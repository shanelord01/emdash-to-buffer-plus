An unofficial plugin. It is not affiliated with, endorsed by or supported by Buffer.

Shares new entries to your Buffer channels, fitted to each network, with delivery tracking, an engagement dashboard, an editor panel and MCP tools.

- **Every network Buffer's API can post to.** Text is fitted to each network's limit, only the description is shortened, and each post carries the entry's image or a link card where Buffer supports one.
- **Tracked delivery.** Each post is followed from your site to the live post. A failed post shows Buffer's reason and can be retried, and an uncertain answer is checked in Buffer before anything is sent again, so nothing posts twice.
- **Reports.** Posts sent, queued and failed, impressions and engagement over 7, 30 or 90 days, top entries and a table per channel, by day in your time zone. A missing figure is shown as missing, never as zero.
- **Editor panel.** Before an entry is first sent, leave out a channel or write custom text for it. Afterwards, see each channel's state and a link to the live post.
- **MCP tools.** Four read-only tools that answer from stored data.

Only entries first published after you install the plugin are shared, and republishing never sends again.

The plugin uses the Buffer API with your personal API key.
