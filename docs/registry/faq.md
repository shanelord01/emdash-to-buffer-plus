**Will it share my existing posts?**
Not on their own. An administrator can share an older entry by hand with Share now in its editor panel. Republishing never sends an entry again.

**Why was a channel skipped?**
The editor panel and the Buffer page say why: the network needs an image and the entry has none Buffer can fetch, the channel is disconnected or locked in Buffer, a Pinterest board is not chosen, the text is too long even without the excerpt, or Buffer's API cannot post to that network (YouTube, WhatsApp, Start Page).

**Why does a figure say "None yet"?**
Buffer reports figures about once a day, and only those a network gives. Missing is not zero.

**Do impressions include posts I made in Buffer?**
Yes. Impressions, engagement and engagement rate are Buffer's figures for every post on the shared channels. Sent, queued and failed count this plugin's posts only.

**Can a post go out twice?**
The plugin is built so it does not. When Buffer's answer is uncertain, it looks for the post in Buffer before sending again. A refused post is sent again only when someone selects Retry.

**How many Buffer requests does it make?**
About 40 to 50 a day for 10 channels. Buffer's limit is per account and shared by every API key and connected assistant: 250 a day and 3,000 in 30 days on the Free plan. Reports pause while less than "Leave for other tools" (25%) is left.

**What if Buffer's limit is reached?**
Posts are not lost. They show "waiting to be sent" with a time and go out by themselves when the limit refills: within 15 minutes, a day, or longer for the 30-day window. Buffer's separate per-channel posting limit can make it refuse a post: select Retry the next day.

**Does it work on every network?**
It follows Buffer's documented rules for each network. It has not been run against a live account on every network yet; please report what you find.
